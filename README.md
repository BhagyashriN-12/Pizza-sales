# Interactive Pizza Sales Dashboard
# Description
This project is an interactive Pizza Sales Dashboard created using Power BI to analyze pizza sales performance. It helps understand sales, orders, quantity sold, pizza categories, pizza sizes, and best and worst-selling pizzas using different charts, KPIs, and filters.

# Tech Stack
The main tools and technologies used in this project are:

📊 Power BI Desktop – Main tool used for data analysis and dashboard creation.

🔄 Power Query – Used to clean and transform the pizza sales data.

🧮 DAX – Used to create calculated measures and KPIs.

🗂️ Data Modeling – Used to organize the data and create relationships for analysis.

📈 Power BI Visualizations – Used to create charts, graphs, KPIs, and interactive dashboard elements
